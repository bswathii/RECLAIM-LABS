# Known limitations and trust gaps

- The IEPF Authority and MCA pages returned HTTP 403 to the current fetcher. IEPF/MCA route cards are therefore official handoff destinations, not proof that the displayed page text is current.
- The app does not determine whether shares exist, whether a holding is in a suspense account, or whether a person is legally eligible. Institution/product words only establish topical relevance; a potential-personal-match label requires explicit reported evidence plus topical relevance and still is not an individual search result or ownership proof. The app does not inspect the document or verify the user's report.
- The app does not file Form IEPF-5, submit documents, contact an RTA, search UDGAM, or read official claim status.
- The app does not infer transfer dates, statutory deadlines, amounts, or outcomes.
- The catalogue is deliberately small: four published records for two route families, not four recoverable assets. It contains no bank-specific holding records, authorized asset-search API, or imported personal dataset. Unsupported clues may produce no route even when a real asset exists.
- The DFS page returned a title only and remains under review/hidden. The India services IEPF URL failed transport. IRDAI's directory was readable, but insurer-specific search/claims were not verified. SEBI MITRA circular metadata was readable, not its operational procedure. These do not expand working claim coverage. See `docs/source-register.md`.
- Sources are manually reviewed. Offline catalogue validation does not verify portal availability, refresh records or implement notice monitoring. Dates describe review/content, not individual financial account freshness. Amounts and deadlines remain null.
- Both real/local preparation and isolated demo persistence are browser-local, unencrypted by the app, and unsuitable for multi-device or multi-user use. Malicious scripts or another user of the same browser profile can access records. Case JSON export does not export discovery drafts or study results. Export/download is not covered by a real-browser test.
- A family-role label is not a shared family workspace or legal authority. A chosen in-app review date sends no notifications and runs no background check. Portal events record clicks, not verified page loads. Separate report events do not update the legacy case-status machine automatically.
- The Qwen3-8B server adapter and `/api/assistant` path are implemented and tested with mocked fetches, including request shape, exact model, Hindi, provider errors/timeouts, malformed/unsafe output, source validation and secret non-disclosure. No real provider request has succeeded in this workspace: `QWEN_ENDPOINT` and `QWEN_API_KEY` are absent, so `npm run qwen:check` reports blockers and inference is not attempted. A real provider must support the exact `Qwen/Qwen3-8B` identifier and the documented complete chat-completions URL contract. The deterministic fallback remains the guaranteed behavior.
- All 69 Node tests pass on pinned Node 22.14.0, including journeys A/B/C discoverability, the synthetic judge-demo and actual-controller tests with stubbed document/storage boundaries. This does not prove browser default actions, download behavior, focus, native form validation or responsive layout. Home was observed in the built-in browser, but click dispatch timed out. Full browser journeys, keyboard/screen-reader testing, and human English/Hindi procedural review remain unverified. Original source excerpts are not translated.
- Docker is not installed in the current worker. The Dockerfile and `.dockerignore` are statically checked, but image build, non-root runtime, and health status remain unverified.
- The optional local discovery timer and report counts are instrumentation, not a completed user study. No faster discovery, conversion, recovery rate or recovered amount has been demonstrated. The comparative protocol is in `docs/manual-usability-test.md`.
- Premium features and RevenueCat are unimplemented. No purchase, restore, entitlement, billing or native distribution flow is present; the free/premium text is a product hypothesis. Official links are not paywalled.
